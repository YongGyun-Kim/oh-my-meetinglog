# 용어집

이 문서의 정의는 입문 학습에 필요한 범위로 줄였다. 자세한 원리와 예제는 연결된 본문에 있다.

## 음성·신호

| 용어         | 뜻                                                     |
| ------------ | ------------------------------------------------------ |
| 파형         | 시간에 따른 신호 진폭을 나타낸 값 또는 그래프          |
| 샘플         | 디지털 신호를 구성하는 측정값 하나                     |
| 샘플레이트   | 1초에 측정한 샘플 수. 채널마다 적용                    |
| Hz           | 1초당 횟수를 나타내는 단위                             |
| 비트 깊이    | PCM 측정값 하나를 표현하는 비트 수                     |
| 채널         | 함께 저장되는 개별 신호 경로                           |
| PCM          | 신호의 샘플값을 숫자로 표현하는 방식                   |
| 코덱         | 음성 등의 데이터를 부호화·복호화하는 방식              |
| 컨테이너     | 음성·영상·메타데이터 등을 담는 파일 구조               |
| 리샘플링     | 샘플레이트를 바꾸는 처리                               |
| 클리핑       | 신호가 표현 가능한 범위를 넘어 잘린 상태               |
| 주파수       | 진동이 1초에 반복되는 횟수                             |
| STFT         | 짧은 시간 구간을 옮겨 가며 주파수 성분을 계산하는 방법 |
| 스펙트로그램 | 시간별 주파수 성분과 세기를 나타낸 표현                |
| Mel          | 사람 청각의 주파수 구별 특성을 참고한 대역 척도        |
| 오프셋       | 구간의 시작 위치 차이. 원본 시각 복원에 사용           |

## 모델·음성 처리

| 용어            | 뜻                                                                 |
| --------------- | ------------------------------------------------------------------ |
| ASR             | Automatic Speech Recognition. 음성을 텍스트로 바꾸는 작업          |
| VAD             | Voice Activity Detection. 말소리가 있는 구간을 찾는 작업           |
| 강제 정렬       | 주어진 텍스트와 음성을 대응시켜 시각을 추정                        |
| Diarization     | 어느 화자가 언제 말했는지 구분                                     |
| Separation      | 섞인 소리를 여러 소스 파형으로 분리                                |
| Enhancement     | 잡음 완화 등 음성 신호 개선                                        |
| 빔포밍          | 다중 마이크의 공간 정보를 활용한 방향성 처리                       |
| DTW             | 두 특징 배열의 시간 진행을 맞추며 비교하는 방법                    |
| HMM             | 관찰되지 않는 상태의 진행과 관찰값의 확률을 모델링                 |
| CTC             | 시간별 출력 경로를 텍스트 배열과 연결하는 학습 방식                |
| 인코더          | 입력을 다음 계산에서 사용할 표현으로 변환하는 부분                 |
| 디코더          | 내부 표현 등을 참고해 출력 배열을 만드는 부분                      |
| Transformer     | attention 등을 사용해 입력 위치 사이의 관계를 학습하는 신경망 구조 |
| Attention       | 관련 입력 위치의 정보에 가중치를 주어 결합하는 계산                |
| 파라미터·가중치 | 학습으로 조정하는 모델 내부 값                                     |
| 학습            | 자료와 목적 함수로 가중치를 조정하는 과정                          |
| 추론            | 준비된 가중치로 새 입력의 출력을 계산하는 과정                     |
| 체크포인트      | 저장된 모델 가중치와 관련 설정                                     |
| Revision        | 저장소의 특정 버전을 식별하는 값                                   |
| 양자화          | 모델 값 등을 더 적은 비트로 표현하는 방법                          |
| MLX             | 이 프로젝트에서 Apple Silicon 음성 모델 실행에 사용하는 도구       |
| Ollama          | 로컬 모델을 관리·실행하고 요청을 받는 도구                         |
| LLM             | Large Language Model. 대규모 언어 모델                             |
| 토큰            | 모델이 다루는 텍스트 등의 기본 단위                                |

| ------------ | --------------------------------------------------------- |
| API          | 프로그램 사이의 요청·응답 약속                            |

| WER          | 단어 단위의 전사 오류 비율                                |
| DER          | 화자 구분 오류 시간의 비율                                |

| 임베딩       | 텍스트 등의 의미적 특징을 숫자 벡터로 표현한 값           |
| RAG          | 검색한 자료를 근거로 생성 모델이 답하게 하는 구성         |
| MCP          | 외부 AI 도구에 데이터·기능을 제공하는 연결 규약           |
| 에이전트     | 모델과 도구를 사용해 여러 단계의 작업을 수행하는 시스템   |
| PoC          | Proof of Concept. 핵심 가설·기술의 가능성을 확인하는 구현 |

## 혼동하기 쉬운 구분

- **16bit 음성과 8bit 모델:** 음성 샘플과 모델 가중치의 표현 정밀도다.
- **화자 구분과 신원 확인:** 같은 사람끼리 묶기와 실제 이름 알아내기다.
- **정렬과 정확도 검증:** 단어 시각 추정과 발언 내용의 정답 확인이다.
- **작은 파일과 적은 메모리:** 저장 크기와 실행 중 자원은 별도다.
- **API 키와 구독 로그인:** 제공자별로 다른 인증·사용 한도 경로다.
- **모델 준비와 품질 통과:** 실행할 파일·서버가 있다는 것과 정답 평가에 합격했다는 것은 별도다.
- **전사와 분석:** 들린 말을 기록하는 작업과 그 의미를 정리하는 작업이다.
- **검색과 생성:** 관련 근거를 찾는 작업과 그 근거로 답변을 만드는 작업이다.
