# 전사 구간 재생과 근거 선택 표시 구현 계획

**목표:** 근거는 요청할 때만 표시하고, 전사·정리는 문장별 줄바꿈을 유지한 덩어리로 읽게 한다. 전사 문장·재생 버튼을 누르면 실제로 재생하며 다음 문장 시작점에서 멈춘다.

**범위:** `AudioPlayer.tsx`의 재생·종료 처리, `RecordingDetail.tsx`의 문장 범위 계산, `TranscriptPane.tsx`의 화자별 표시, `AnalysisPane.tsx`의 근거 토글, 관련 CSS·테스트·README. 저장 데이터·근거 ID·프롬프트·내보내기는 유지한다. 샘플 7:26~7:49는 이미 같은 화자의 턴에 속하므로 재전사나 데이터 병합은 하지 않는다.

사용자의 진행 지시에 따라 이 세션에서 직접 구현한다. 기존 미커밋 변경·개인 음성을 보존하고 커밋·push는 하지 않는다. 새 의존성을 추가하지 않는다.

## 1. 문장 재생

- [x] 테스트에서 전사 버튼이 `play()`를 호출하지 않는 문제를 재현한다.
- [x] `Player.play(startMs, endMs)`를 추가한다. 다음 문장 시작이 현재 시작보다 뒤면 그곳에서 종료하고, 마지막 문장·겹친 시각은 문장 종료 시각을 사용한다.
- [x] 원본 재생바는 연속 재생을 유지한다. 재생 실패 안내, 일시정지·재개, 구간 변경·수동 탐색·화면 종료 시 종료 예약 정리를 확인한다.

## 2. 묶음 표시와 근거

- [x] 근거 기본 숨김·보기/숨기기·재분석 없음, 한 턴의 여러 문장·각 문장 편집 유지 테스트를 먼저 추가한다.
- [x] 턴 헤더에 화자·시각·재생을 모으고 문장마다 줄을 바꾼다. 문장 클릭·키보드 선택·편집·검토 표시·가상 스크롤 초안을 유지한다.
- [x] 정리의 같은 주제 본문을 연속된 줄로 표시한다. 근거 토글은 저장된 연결을 보여 주며 모델을 다시 호출하지 않는다.
