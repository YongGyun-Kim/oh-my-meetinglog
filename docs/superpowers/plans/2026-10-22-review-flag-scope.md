# 검토 표시 범위와 기본 화면 정리

**목표:** 검토 표시를 실제 감지된 문장에 한정하고, 중복·경계 표시를 기본 화면에서 줄인다. 겹침 판정 임계값과 화자 배정은 바꾸지 않는다.

**범위:** 음성 처리의 내부 `Word`에 선택적인 검토 표시를 남긴다. 저장 직전 조립에서 해당 문장의 단어에 붙은 표시만 모은다. 구버전 단어 정보가 없으면 해당 원래 구간의 표시를 보존한다. 최종 전사·모델 입력·내보내기에 단어 목록을 추가하지 않는다. 화면은 턴마다 검토 항목을 한 번 요약하며, 세부 사유는 `검토 정보 보기`에서 확인한다.

사용자의 진행 지시에 따라 직접 구현한다. 기존 미커밋 변경·개인 녹음을 보존한다. 새 의존성, 재전사·재분석, 커밋·push는 추가하지 않는다.

- [x] 단어별 경고 위치·인접 문장 전파 방지·구버전 읽기 회귀 테스트를 먼저 추가한다.
- [x] `domain.py`, `recordings/alignment.py`, `engines/local_speech.py`, `transcripts/assembly.py`에서 검토 정보를 보존하고 문장별로 집계한다. 같은 화자의 턴·본문·시각은 유지한다.
- [x] `TranscriptPane.tsx`에서 미확인 화자와 확인 필요 배지를 중복 표시하지 않는다. 기본으로 시간 정렬 확인만 턴마다 한 번 보여 주고, 겹침·경계·상세 사유는 사용자가 켰을 때 해당 문장에 표시한다. 기존 편집·부분 재생·가상 스크롤은 유지한다.
- [x] 기존 샘플은 저장된 원래 구간과 현재 문장을 대조해 검토 정보만 보완 가능한지 확인한다. 원문·시각·화자·문장 ID는 변경하지 않는다. 판정 위치를 복원할 수 없는 구간의 경고는 임의로 없애지 않는다.
- [x] 전체 자동 검사, 실제 샘플 화면, 상세 표시의 모델 미호출을 확인하고 README·검증 기록을 갱신한다.
