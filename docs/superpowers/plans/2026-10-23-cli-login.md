# CLI 로그인 연결 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 웹 설정에서 Codex·Claude Code 설치·로그인 상태를 확인하고 공식 CLI 로그인을 시작·취소한다.

**Architecture:** FastAPI가 고정된 CLI 인증 명령만 실행한다. 로그인은 백그라운드 프로세스로 관리하고 상태만 웹에 반환한다. 인증 정보는 공식 CLI가 계속 관리한다.

**Tech Stack:** 기존 Python subprocess/threading, FastAPI, React·TypeScript. 새 의존성 없음.

**Spec:** 사용자가 확정한 현재 대화: 초기 Codex·Claude Code CLI, 웹 설정, 로그인부터 구현. 직접 OAuth·모델 선택·정리 실행·외부 MCP는 후속 범위다.

## Global Constraints

- 이미 로그인된 계정과 기존 전사·정리 처리를 유지한다.
- 임의 실행 명령·인수·인증 정보를 웹에서 입력받지 않는다.
- CLI 인증 출력·토큰·이메일·인증 URL을 응답이나 앱 로그에 노출하지 않는다.
- 로그인 창은 서버 컴퓨터에서 열린다. 현재 루프백·출처 제한을 유지한다.
- 로그인 프로세스는 중복 실행을 막고 취소·5분 시간 제한·서버 종료 시 정리한다.
- 서비스 문구는 docs/service-copy.md를 따른다.

## Review Focus

- CLI 미설치·상태 확인 실패를 미로그인과 구분한다.
- 이미 연결된 계정을 다시 로그인시키거나 로그아웃시키지 않는다.
- 연속 클릭·취소 후 재시도에서 이전 프로세스가 새 상태를 덮어쓰지 않는다.
- 자격 증명이 포함된 CLI 출력은 성공·실패 응답에 노출하지 않는다.
- 브라우저가 닫혀도 로그인 프로세스가 무기한 남지 않는다.
