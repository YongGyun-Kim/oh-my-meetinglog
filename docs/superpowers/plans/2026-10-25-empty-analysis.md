# 빈 분석 결과 수정과 검증

## 문제와 변경

- 기존 로컬 호출은 출력 스키마를 Ollama의 `format`에 전달했지만 프롬프트에는 전체 구조를 넣지 않았다. 실제 전사에서 제목만 있는 결과 또는 빈 `sections`를 반환해 `empty_analysis`로 실패했다.
- 공통 시스템 프롬프트에 `FormAnalysisBody` 스키마를 함께 전달한다. 생성과 구간 통합, 로컬·CLI·API 경로에 같은 구조를 설명한다. 프롬프트 버전은 5다.
- 안내만 추가한 실제 모델 검사에서는 빈 결과가 다시 나왔다. 로컬 생성용 스키마를 별도로 만들고 `sections`와 본문을 비워둘 수 없게 제한한다. 양식별 섹션 제목과 문단·비교표·후속 행동의 위치도 제한한다. 저장된 '언급 없음' 섹션은 기존 형식으로 계속 읽는다.
- 담당자 ID와 원문 이름은 동시에 채울 수 없게 로컬 출력 스키마를 제한한다.
- 빈 결과, 양식 오류, 근거 불일치의 사용자용 오류를 구분한다. 기존 근거·담당자·기한 검증과 재시도는 유지한다.
- 근거 ID나 담당자 검증에 실패하면 잘못된 항목을 JSON으로 재요청에 포함한다. 행동의 담당자·기한 오류는 첫 항목에서 멈추지 않고 한 번에 모아 전달한다. 최초 생성과 수정 1회의 제한은 유지한다.
- 통합 결과에 같은 제목의 섹션이 반복되면 내용을 하나의 섹션으로 모으고 완전히 같은 항목만 제거한다. 알 수 없는 제목은 계속 거부하며, 합친 결과에도 근거 검증을 수행한다.
- 기존 분석과 전사 데이터 형식은 바꾸지 않는다. 실제 모델 검증은 녹음이나 분석 기록을 저장하지 않는다.

## 실제 모델 회귀 검사

Ollama와 로컬 분석 모델을 준비하고, 앱이 저장한 전사 JSON 경로를 지정한다.

```sh
MEETINGLOG_TEST_TRANSCRIPT=/absolute/path/to/transcript.json PYTHONPATH=backend/src \
  uv run --no-sync pytest tests/test_live_analysis.py -m live -q -s
```

일반 회의·요구사항 협의·검토와 결정·진행 점검·사용자 인터뷰를 각각 분석한다. 실제 입력 분할, 모델 생성, 검증 오류 재시도, 구간 통합, 원래 문장 ID 복원과 최종 검증을 거친다. 특정 양식만 확인할 때는 `-k meeting`처럼 필터를 붙인다. 파일을 지정하지 않으면 건너뛴다. 비공개 전사와 녹음은 저장소에 추가하지 않는다.

## 검증 기록

- 변경 전 코드에서 실제 전사의 일반 회의 분석이 `empty_analysis`로 실패하는 것을 새 live 테스트로 확인했다.
- 실제 녹음은 586문장이다. 스키마를 포함한 프롬프트 크기로 분할하므로 일반 회의는 기존 3구간에서 4구간으로 늘어난다. 입력 한도는 유지한다.
- 실제 `gpt-oss:20b`로 요구사항 협의·검토와 결정·진행 점검을 통과했다. 중복 섹션과 복수 담당자 오류 처리를 수정한 뒤 일반 회의·사용자 인터뷰를 다시 실행해 통과했다. 각 검사는 실제 전사의 4구간 생성과 3회 통합, 원래 문장 ID 복원과 최종 근거 검증을 포함한다. 결과는 녹음 기록에 저장하지 않았다.
- Python 162개, 웹 42개 테스트와 lint·형식·타입 검사·빌드를 통과했다.
- 브라우저 7개 중 5개는 통과했다. `plays a transcript sentence until the next sentence and allows continuous playback`와 `captures fake microphone audio and finalizes before processing`는 재생 시각 진행·종료 대기에서 실패했다. 변경 전 `main`(`0df5c43`)에서도 같은 두 검사가 실패하는 것을 별도 실행으로 확인했다. 이번 분석 수정에서 재생 코드나 검사 기준은 바꾸지 않았다.

스키마 안내를 추가해도 모델의 의미 해석이나 누락 방지를 보장하지 않는다. 실패 결과를 통과시키기 위해 검증을 완화하지 않는다. 참고: [Ollama의 구조화 출력 안내](https://docs.ollama.com/capabilities/structured-outputs).
