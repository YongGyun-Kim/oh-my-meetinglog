# README 데모용 인터뷰 후보

확인일: 2026-10-20. 한국어 음성 전사 데모에 사용할 수 있는 유튜브 원본이 있는 인터뷰를 간단히 조사했다. 두 후보 모두 FC SEOUL이 제작했으며, Wikimedia Commons에 영상 파일과 CC BY 3.0 라이선스 검토 기록이 있다. 긴 팟캐스트 대신 짧은 인터뷰 형식이다.

설명란의 배경 음악에만 CC 표시가 붙은 검색 결과는 후보에서 제외했다. 위 근거는 영상 전체의 라이선스 표기와 과거 검토 기록이다. 현재 유튜브 페이지의 라이선스를 직접 확인한 결과로 표현하지 않는다.

## 실제 사용할 때

Commons의 해당 파일 페이지에서 원본 파일과 라이선스 근거를 함께 확인할 수 있다. 공개 결과에는 영상 제목, 제작자 FC SEOUL, 원본 URL, [CC BY 3.0 링크](https://creativecommons.org/licenses/by/3.0/), 사용 구간과 변경 내용을 기록한다. 예를 들어 음성 추출·일부 발췌·자동 전사·앱 화면 촬영 여부를 표시한다. 제작자나 출연자가 우리 서비스를 보증하는 것처럼 표현하지 않는다.

배경 음악 등 별도 권리와 인물의 이용 맥락은 사용할 구간에서 추가 확인한다. 후보 조사 시점에는 라이선스 기록 확인까지만 진행했다.

## 선택과 후속 실행

한국어 입력을 우선해 **심원성·이태석 인터뷰**를 선택했다. 이후 Commons 원본을 받아 전체 음성을 추출하고, 실제 로컬 전사·분석 결과를 README의 화면과 영상에 반영했다. 출처·변경 내용·오인식·검증 범위는 [한국어 인터뷰 데모 기록](../verification/2026-10-20-korean-interview-demo.md)에 남겼다. 안기훈·백상훈 인터뷰는 실행하지 않았다.
