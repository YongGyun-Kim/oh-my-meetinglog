# 검토 표시의 범위와 기본 노출 개선

확인일: 2026-10-22. 개인 대화와 검증용 데이터는 Git 제외 경로 `data/verification-2026-10-22-review/`에 둔다.

## 변경

단어별 판정을 발언 전체로 합친 뒤 모든 문장에 복사해 경고가 퍼지는 문제가 있었다. 내부 단어 정렬의 `Word.review_flags`에 판정 위치를 보존하고 해당 문장에 들어간 단어의 표시만 모은다. 중복 제거 경계는 남은 첫 단어에 표시한다. 경고가 다르다는 이유로 같은 화자의 턴을 나누지 않는다. 최종 전사·모델 입력·내보내기에는 단어 목록을 추가하지 않는다.

구버전의 `Word.review_flags`는 `null`이며, 이때는 원래 발언 구간의 검토 표시를 보존한다. 빈 목록은 해당 단어에 검토 표시가 없다는 뜻이다. 정렬이 불완전한 구간은 기존 구간의 표시와 `alignment_uncertain`을 유지한다. 기존 자료에서 정확한 위치를 알 수 없는데도 경고를 없애지 않는다.

화면은 기본으로 미확인 화자 이름과 턴당 한 번의 시간 정렬 확인을 표시한다. **검토 정보 보기**를 켜면 문장별 겹침·화자 전환·처리 구간 경계가 나타난다. 미확인 화자의 ‘화자 확인 필요’ 배지는 중복 표시하지 않는다. 실제 겹침을 확정한 표현 대신 ‘발언 겹침 가능’이라고 표시한다. 표시 전환은 모델 호출·전사 수정을 발생시키지 않는다.

겹침 길이·비율이나 화자 우세도에 따른 판정 임계값은 이번에 변경하지 않았다. 화자 배정, 본문, 문장 시각, 분석 프롬프트도 유지한다.

약 28분 샘플의 저장된 단어 정렬·화자 구간으로 검토 표시를 다시 계산했다. 새 음성 인식이나 대화 분석은 실행하지 않았다. 412개 턴·586개 문장의 본문·화자·시각을 대조했고 기존 문장 ID를 보존했다.

## 검증과 게시

`bash scripts/check.sh`를 통과했다. Python 테스트 93개, 웹 컴포넌트 테스트 27개, Playwright 시나리오 4개가 통과했다. Python 정적 검사·포맷, TypeScript 검사, 웹 빌드와 `git diff --check`도 통과했다. 기존 Starlette/AnyIO 별칭 폐기 예정 경고 1개와 브라우저 시험 환경의 색상 설정 경고가 남는다.

새 회귀 검사는 같은 화자의 정상 문장에 경고가 퍼지지 않는지, 단어별 경계 위치와 중복 제거 위치가 보존되는지, 구버전의 표시가 소실되지 않는지, 상세 정보가 기본으로 숨겨지고 표시 전환 시 모델·편집 API를 호출하지 않는지 확인한다. 기존 부분 재생·편집 충돌·스크롤 초안·내보내기 시나리오도 통과했다.

샘플의 검토 정보는 새 전사 버전으로 게시했다. 이전 전사·정리·작업 이력과 갱신 전 DB 백업을 보존했다. 새 전사의 정리 모델 입력이 이전과 완전히 같다는 것을 비교한 뒤 기존 정리 본문을 새 전사 버전에 연결한 결과 버전을 저장했다. 새 모델 추론은 없으며 정리 본문·근거 문장 ID는 동일하다. 작업 이력에 `review_metadata_updated`를 남겼다.

웹·API·워커를 재시작한 뒤 실제 샘플에서 기본 문장 배지 숨김, 겹침 상세 표시, 미확인 화자 중복 배지 제거, 다시 숨기기를 확인했다. 표시 전환 중 POST/PATCH 요청은 0회였고 브라우저 실행 오류는 없었다. 이전 전사·정리 내보내기도 계속 열리며 현재 정리는 전사 버전과 일치한다. 390px 너비에서도 가로 넘침 없이 검토 정보 버튼에 접근했다.

실제 음성을 듣고 경고의 오탐·누락을 채점하지 않았다. 화면 크기 확인은 모바일 실기기 검사가 아니다.
