# 전사 구간 재생과 근거 선택 표시

확인일: 2026-10-22. 개인 음성·대화 본문·화면 캡처는 Git 제외 경로인 `data/verification-2026-10-22-playback/`에만 둔다.

## 원인과 변경

전사 재생 버튼은 `AudioPlayer.seek()`로 `currentTime`만 바꾸고 `play()`를 호출하지 않았다. 브라우저에서 버튼 클릭 후 재생 위치가 이동해도 `paused: true`인 것을 재현했다.

문장·재생 버튼 클릭은 해당 문장부터 다음 문장 시작까지 재생한다. 마지막 문장 또는 다음 시작이 현재 시작보다 늦지 않은 경우에는 문장 종료 시각을 사용한다. 재생 시각과 속도에 맞춰 종료를 예약하고 미디어 이벤트로 다시 확인한다. 일시정지·버퍼링·새 구간 선택·수동 탐색·화면 종료 시 예약을 정리한다. 원본 재생바를 직접 조작하면 부분 재생을 해제한다. 재생 실패는 화면에 표시한다.

샘플 7:26~7:49는 이미 같은 화자의 턴에 저장돼 있었다. 문장마다 시각·재생·편집 행과 여백을 반복해 별개 덩어리처럼 보였다. 화자·시각·재생은 턴 헤더로 모으고 문장은 줄을 바꿔 표시한다. 문장별 편집·검토 표시·수정 초안은 유지한다. 같은 화자의 발언은 계속 같은 턴으로 표시하므로 7:49에 시작한 후속 문장도 실제 화자 경계까지 이어진다.

대화 정리는 기본으로 근거를 숨긴다. **근거 보기/근거 숨기기**는 저장된 연결의 표시만 바꾸며 모델을 호출하지 않는다. 같은 주제의 본문은 문장별 줄바꿈을 유지한 덩어리로 표시한다. 전사·분석 데이터·근거 ID·프롬프트·내보내기는 변경하지 않는다.

## 실제 샘플 확인

데스크톱 Chromium에서 샘플의 지정 문장을 클릭해 다음을 확인했다.

| 항목                            | 결과                           |
| ------------------------------- | ------------------------------ |
| 턴 시작 표시                    | 07:26                          |
| 같은 턴의 문장 / 헤더 재생 버튼 | 6개 / 1개                      |
| 클릭 후 실제 재생 시작          | 452.952초, `paused: false`     |
| 다음 문장 시작에서 종료         | 455.544초, `paused: true`      |
| 해당 문장의 편집 창 열기·취소   | 통과, 원본·수정 버전 변경 없음 |
| 근거 기본 숨김 → 보기 → 숨김    | 통과                           |
| 표시 전환 중 분석 요청          | 0회                            |
| 390px 화면 가로 넘침            | 없음                           |
| 브라우저 실행 오류              | 없음                           |

새 음성 인식이나 대화 분석은 실행하지 않았다. 기존 샘플 결과를 그대로 사용했다. 화면 크기 검사는 모바일 실기기 검사가 아니다. Safari·iOS·안드로이드 실기기, 백그라운드·화면 잠금 상태, 전사·요약의 의미적 정확도는 검증하지 않았다. 웹 타이머와 미디어 이벤트에 의존하므로 샘플 단위 오디오 편집 수준의 종료 정밀도를 보장하지 않는다.
